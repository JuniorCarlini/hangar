# ADRs — Registros de decisão de arquitetura

Formato: contexto → decisão → consequências. Um arquivo por decisão,
numerado, nunca reescrito: se a decisão mudar, cria-se um ADR novo que
substitui o anterior (e o antigo recebe `Status: Substituído por NNNN`).
